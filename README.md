# MedSync

O MedSync é uma aplicação web desenvolvida como projeto acadêmico do curso de Sistemas de Informação, com o objetivo de facilitar o gerenciamento de clínicas e consultórios médicos.

O sistema permite o cadastro e gerenciamento de pacientes, médicos, atendentes e consultas, centralizando informações importantes em uma única plataforma. A proposta é tornar os processos administrativos mais organizados, eficientes e acessíveis, contribuindo para uma melhor experiência tanto para os profissionais da saúde quanto para os pacientes.

## Funcionalidades

* Cadastro e gerenciamento de pacientes;
* Cadastro e gerenciamento de médicos;
* Controle de atendentes;
* Agendamento e gerenciamento de consultas;
* Painel administrativo para visualização de informações;
* Interface web responsiva e intuitiva;
* Organização modular do código para facilitar manutenção e evolução do sistema.

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* Banco de Dados (simulado para fins acadêmicos)

## Objetivo

Este projeto foi desenvolvido com fins educacionais, aplicando conceitos de desenvolvimento web, organização de código, modelagem de sistemas e gerenciamento de dados, servindo como base para futuras implementações e aprimoramentos.
